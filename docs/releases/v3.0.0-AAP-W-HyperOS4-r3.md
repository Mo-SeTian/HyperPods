# HyperPods HyperOS 4 · 构建 32

版本：`3.0.0-AAP-W-HyperOS4`，构建号 **32**，应用 ID：`io.github.mo_setian.hyperpods`。

## 本次更新

- 重构原生耳机设置界面：浅色纯白、蓝色强调，统一深色模式、列表、页面过渡和返回滚动位置。
- 首页显示独立左右耳电量，耳机仓仅在数据有效时显示；耳机和耳机仓使用各型号已有图片。
- 聆听模式使用通透—自适应—降噪连续滑块，自适应区间可调耳机原生强度；优化拖动收缩、松手原位展开和等待确认时的反馈。
- 均衡器通过下拉选择推荐或自定义，仅自定义显示低、中、高三段调节，并保留型号与固件兼容提示。
- 统一更多设置、姿态与手势测试、连接诊断的布局和对齐；关于页将“重试状态同步”独立放在模块状态下方。
- 恢复系统默认字体，移除完整内置字体，减少安装包体积。
- 完善首次连接、快速出仓及控制通道停滞时的有限探测和恢复，保护恢复中、断连、换会话及后台期间的过期操作。
- 完善摘戴耳、对话结束后的自动续播及手动暂停、通话和切换音频设备时的取消保护。

正式版保留原有设置能力判断、连接诊断、历史日志查看、复制和分享；本地 Root 日志采集、临时协议追踪和预览工具未纳入发行代码。

## 安装与升级

已安装独立包 `io.github.mo_setian.hyperpods` 的用户可直接覆盖升级，沿用同一正式签名。安装后确认 LSPosed 模块及蓝牙、系统界面作用域正确，并重启手机，让作用域进程加载构建 32。

旧 `moe.chenxy.hyperpods` 包和 `.uipreview` 测试包属于不同应用，不能由本附件覆盖。首次从旧包迁移时，按仓库的独立包迁移说明操作。

附件为可直接安装的 APK，无需解压；文件名末尾是最终已签名 APK 的 MD5 前 8 位。

## 验证范围

本轮 UI 完整回归通过 432 项单元测试、245 项 Android 交互测试；型号图片修复另通过 24 项相关交互回归，并核对 11 组型号、有仓和无仓共 22 张实际截图。发行流程执行构建、Lint、原生边界检查及正式签名验证。

不同 HyperOS 版本、耳机型号及固件仍需真机确认。升级后重点复测首次连接、单耳出仓、通透／降噪切入自适应、摘戴耳续播和对话结束后的续播行为。
