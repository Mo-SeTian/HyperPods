# 耳机原生三段均衡器

入口为“更多控制 → 音频 → 均衡器”，沿用项目现有的 Miuix 控件、蓝色强调、浅色/深色主题、页面过渡与独立滚动位置。

- 下拉选择“推荐”时，仅显示模式及说明，由耳机使用推荐调音。
- 选择“自定义”时显示低音、中音、高音三段横向滑杆及重置。每段为 `0..100`，`50` 为默认值，不将协议数值标为 Hz、dB 或百分比。
- 拖动时合并更新，最多每 100 毫秒发送一次；松手立即发送最后一个值。重置将三段设为 `50/50/50`，保持自定义模式。
- 同一连接中切换推荐与自定义时保留已知的三段值。写入失败恢复最近已知状态；后续真实耳机回报始终具有优先权。断开后不将旧连接缓存冒充新连接的回报。

## 协议来源与改编

参考 [LibrePods main 89356c0 的 CustomEq](https://github.com/librepods-org/librepods/blob/89356c08cea3db0b6b54792d9329d09a87cc85fa/android/app/src/main/java/me/kavishdevar/librepods/data/CustomEq.kt) 及 [AACPManager](https://github.com/librepods-org/librepods/blob/89356c08cea3db0b6b54792d9329d09a87cc85fa/android/app/src/main/java/me/kavishdevar/librepods/bluetooth/AACPManager.kt)，并核对 `android/rewrite` 分支 `3d4d270` 的发送路径和固件判断。保留 LibrePods 的来源说明，协议代码按本项目结构改编。

完整设置包为：

```text
04 00 04 00 63 00 05 00 01 state low mid high
state = 01：推荐；02：自定义
low / mid / high = 00..64（十进制 0..100）
```

该协议与已有但未接入界面的 `0x53` 八浮点 EQ 不同，本次不修改后者。不增加频率、Q 值、音效预设或手机端 DSP。

收包时严格校验完整包长、长度字段、设置类型、模式与三段范围；不把短包、查询包或未知变体当作默认调音。成功发送后更新本地值，在连接诊断中标记“已发送，耳机尚未回报”；发送失败不修改协议缓存，真实回报到来后覆盖本地值。

## 兼容与读取边界

项目已有型号中的 AirPods 4、AirPods 4 ANC、两款 AirPods 5、AirPods Pro 2 Lightning / USB-C、AirPods Pro 3 显示入口。未收到 EQ 回报时，参照 LibrePods rewrite，识别标准固件版本（如 `9A348`）的代数，至少为 9 才允许操作；无法识别的版本不猜测支持，真实有效 EQ 回报可确认支持。未识别的新型号若实际回报有效 EQ，也允许使用。

首次读取沿用已有的耳机状态订阅。目前上游明确的 EQ 设置格式不包含单独查询请求，本次不猜测新查询指令。已知固件兼容但尚未收到当前 EQ 时，不虚构已选模式；界面说明手动选择会从默认三段值 `50` 开始。打开页面、切换页面或收到状态广播均不会自动写入默认值。

EQ 为可选功能，不计入电量、佩戴、设备信息或原有设置同步的必需条件；不会因 EQ 无回报而重连、重发握手或循环重试。离开页面、切换模式、控制连接重建时取消待发送的滑杆操作；命令携带控制连接编号，旧连接的延迟命令会被忽略。

## 验证范围

自动化覆盖完整及异常协议包、模式切换、写入失败、真实回报覆盖、固件判断、旧连接命令隔离和现有状态恢复不写 EQ；界面测试覆盖下拉选择、推荐模式隐藏全部调节、单段调节保留其余值、松手发送最终值、重复失败恢复、重置及返回滚动位置。

模拟器可验证界面与状态流转，无法验证真实耳机的调音效果或固件是否持久保存设置；这两项需要兼容耳机实测。

本次验证：358 项 JVM 测试、36 项模拟器界面与导航测试通过（包括动画倍率 1 与 0），Debug APK 构建通过，Lint 无错误。界面截图保存在项目空间的 `analysis/eq-ui/`，仅使用模拟耳机数据，未在实体手机上安装测试包。

主要代码位置：`utils/CustomEq.kt` 定义数据与校验，`utils/AACPManager.kt` 处理协议收发，`pods/L2CAPController.kt` 处理受信任的设置命令与连接隔离，`ui/components/EqualizerPage.kt` 实现下拉菜单、滑杆及交互状态，`ui/PodDetailPage.kt` 接入入口与导航。

复现构建检查需要 JDK 22 与本项目配置的 Android SDK：

